PannamOS is a private BrowserOS-derived Chromium browser for local-first AI browser work. It runs the assistant, provider setup, sessions, Goal Mode state, and verification data locally without requiring BrowserOS login or BrowserOS cloud sync.

**Private fork. Local-first. Built for durable browser automation.**

## Three Ways to Use AI

<Columns cols={3}>
  <Card title="Chat Mode" icon="message">
    Ask questions about the page you're viewing. Summarize articles, extract data, translate content, and keep provider state local.
  </Card>
  <Card title="Goal Mode" icon="robot">
    Describe a task and watch AI execute it: clicking, typing, navigating. Automate form filling, data extraction, and multi-step workflows.
  </Card>
  <Card title="Workflow Mode" icon="sitemap">
    Run repeatable browser automations with scoped local provider and connector access.
  </Card>
</Columns>

## Quick Start

<Steps>
  <Step title="Build or install PannamOS">
    Use the private Windows build and install runbooks. Do not use public BrowserOS installers as the PannamOS install path.
  </Step>
  <Step title="Import from Chrome">
    Navigate to `chrome://settings/importData` and import your bookmarks, passwords, and settings in one click.
  </Step>
  <Step title="Configure your AI">
    PannamOS supports local ChatGPT Plus/Pro OAuth, OpenAI API keys, and OpenAI-compatible local endpoints. BrowserOS account login is not required.

    <Card title="Set up your LLM provider" icon="key" href="/features/bring-your-own-llm">
      Configure ChatGPT Plus/Pro OAuth, OpenAI, or local OpenAI-compatible endpoints
    </Card>
  </Step>
  <Step title="Try it out">
    Open any webpage and press the **Assistant** button in the toolbar. Ask a question about the page, or describe a task to automate.
  </Step>
</Steps>

## Which AI Model Should I Use?

<Tabs>
  <Tab title="For Chat Mode">
    **Any model works great**, including local LLMs.

    - **Ollama** or **LM Studio** — Free, runs locally, great for quick questions
    - **Gemini Flash** — Fast and affordable
    - **Claude or GPT-4** — Best quality responses

    Chat Mode just needs to understand the page and answer questions—local models handle this well.
  </Tab>
  <Tab title="For Agent Mode">
    **Use Claude Opus 4.5 for best results.**

    | Model | Speed | Quality |
    |-------|-------|---------|
    | Claude Opus 4.5 | Slower | Best |
    | Claude Sonnet 4.5 | Medium | Great |
    | Claude Haiku 4.5 | Fast | Good |
    | Gemini Flash | Fast | Good |

    <Warning>
    Local LLMs are not yet powerful enough for Agent Mode. The model needs strong reasoning to click the right elements and handle multi-step tasks.
    </Warning>
  </Tab>
</Tabs>

## Why PannamOS?

<Columns cols={2}>
  <Card title="Privacy-First" icon="shield-check">
    Run AI with local OAuth/API provider settings. Your browser sessions and Goal Loop state stay in the PannamOS local data directory.
  </Card>
  <Card title="Open Source" icon="code-branch">
    Derived from the AGPL-3.0 BrowserOS codebase with attribution preserved.
  </Card>
  <Card title="Works with Your Tools" icon="plug">
    Supports local MCP connector setup and rejects remote/cloud connector defaults in the private build.
  </Card>
  <Card title="Chrome Compatible" icon="chrome">
    All your Chrome extensions work. Import bookmarks, passwords, and settings in one click.
  </Card>
</Columns>
